# BAON — Motion Lab

Живой прототип моушен-языка бренда. Открывается в любом браузере, без интернета
и без сборки.

## Файлы

| Файл | Что это |
|---|---|
| `baon-motion-lab.html` | Интерактивная страница: герой-кадр, логотип, палитра, типографика, тайминги, триптих, снег |
| `baon-motion-lab.mp4` | Запись первых 6 секунд (9:16, 20 fps) — как выглядит в движении |
| `hero-frame.png` | Кадр героя (768×1365) — можно использовать как референс |
| `brand-tokens.json` | Токены бренда для кода и After Effects (цвет, шрифт, тайминги) |
| `brand-tokens.css` | Те же токены в виде CSS-переменных и утилит |

## Как смотреть

1. Откройте `baon-motion-lab.html` в браузере.
2. Прокрутите вниз: каждая секция — отдельный приём.
3. В секции «Логотип» нажмите «Проиграть ещё раз».
4. В секции «Триптих» наведите курсор (на телефоне — коснитесь), чтобы увидеть сдвиг полос.

## Что внутри

- **Герой:** аврора-градиент (дрейф 46–58 с), звезда (24 с на оборот), антиква,
  трекинг-подзаголовок, линия.
- **Логотип:** раскрытие по маске 1,2 с, монограмма, повтор.
- **Палитра:** крем, эспрессо, тиль, розовый + пропорция 60/30/10.
- **Типографика:** антиква + гротеск с трекингом.
- **Тайминги:** длительности и кривая ease-out.
- **Триптих:** приём кампаний 2024 года.
- **Снег:** canvas, редкие крупные хлопья.

## Токены

Файлы `brand-tokens.json` и `brand-tokens.css` — машиночитаемая версия палитры,
типографики и таймингов. Их можно подключать в прототипы и передавать разработке.

## Важно

- Шрифты — системные аналоги (Cormorant/Playfair/Georgia, Inter/system-ui).
  Финальные шрифты бренда нужно запросить у клиента.
- Логотип в прототипе набран текстом, а не вектором. Для продакшена — только
  официальный файл.
- Прототип не является финальным дизайном: это доказательство принципов
  из `04-motion-brief.md`.
