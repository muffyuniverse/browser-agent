## 3. Почему не удалось получить сайт

`baon.ru` резолвится в `178.72.133.98`, но соединение по 443 порту обрывается
по таймауту с сети исполнителя. Проверены:

- прямой HTTPS-запрос с мобильным User-Agent;
- `www.baon.ru`, `m.baon.ru`;
- публичные прокси (`allorigins`, `codetabs`, `r.jina.ai`);
- Google Translate-прокси;
- `web.archive.org` и `archive.ph`.

Прокси получали **522 Connection timed out** — то есть проблема на стороне
origin-сервера, а не только в сети исполнителя. Возможные причины: сайт недоступен
из-за рубежа, блокировка дата-центровых IP или временная авария.

**Следствие:** визуальный анализ сайта (главная, каталог, lookbook) не сделан.
Компенсировано скриншотами приложения и YouTube-материалами.

## 4. Что это значит для выводов

1. **Факты о бизнесе** (выручка, число магазинов) взяты из вторичных источников
   и сниппетов, а не из первоисточника. Перед публикацией — проверить.
2. **Визуальный анализ** опирается на реальные ассеты 2021–2026, а не на брендбук.
   Это достаточно для дизайна, но не для юридически точного воспроизведения логотипа.
3. **Шрифты** не идентифицированы. Рекомендованы аналоги с кириллицей.
4. **Сайт** не изучен. Если клиент даст доступ или скриншоты — добавить в пакет.
